# T4: память 3989 MiB, цель скорости ещё не достигнута

Проверенный код `33641b98b154e95cb14849c6f3264aee23eefd78`.
Приватный [Kaggle-запуск №19](https://www.kaggle.com/code/diassamenov/soup-kernel-lab-auto/19).
Один полный повтор base/solution; профиль — отдельный диагностический запуск.

| Метрика | Base | Solution |
|---|---:|---:|
| Полное время, с | 85.84 | 64.73 |
| Training loop, с | 56.38 | 42.80 |
| Пик nvidia-smi, MiB | 14345 | 3989 |
| Eval loss | 2.04970 | 2.04952 |

Штатный speedup **1.3261x**, memory ratio **3.5961x**, eval delta **-0.009%**.
Цель пользователя <5000 MiB выполнена; ≤50 с пока не достигнута.
По сравнению с прежними 63.25 с / 5959 MiB новый пик ниже на 1970 MiB,
но время не улучшено. Разные сессии и число повторов не позволяют
приписывать разницу времени одному конкретному патчу.

111 unit-тестов, 79 регрессионных тестов, все **10/10 проверок допуска**.
Доля собственных кернелов — **14.8%**. Loss: первая точка отличается на
0.01%, средняя кривая — на 0.04%. Шаги, адаптер, trainer settings, метрики
и Soup rewind прошли исходную проверку. Hidden/jury admission не заявляется.

Причины снижения памяти: общие views исходных packed NF4 параметров без
дублирующих старых буферов; сохранение узкого MLP-входа с пересчётом frozen
gate/up в backward; variable-length native attention с сохранением малых K/V;
прямое преобразование BHLD в packed layout; Half logits с FP32 редукциями;
FP16 decode для FP16 backward GEMM. Кэшируются только frozen масштабы,
не распакованные матрицы весов. Время создания и память кэшей входят в замер.

Параметры, данные, батчи, optimizer, dropout и флаги trainer не менялись.
FP16-хранение внутренних активаций унаследовано из версии 16: это прежнее
изменение округления, не обещание побитовой идентичности FP32 базе.
SwiGLU организаторов используется без изменений и не засчитывается своим.
Вызовы native attention используют внутренний API PyTorch 2.11; перенос
на другую версию требует проверки. Стартовые harness/tests/task/templates неизменны.
