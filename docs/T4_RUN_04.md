## Изменения относительно RMSNorm-кандидата

- Frozen MLP сохраняет операнды SwiGLU в том fp16-виде, в котором их уже
  потребляет bitsandbytes, вместо дополнительных fp32-копий. Отдельные
  gate/up casts сохраняют порядок округления градиентов. Пример SwiGLU
  остаётся исходным и не засчитывается собственным кернелом.
- Training head обрабатывает logits блоками по 256 строк и сохраняет только
  нормализаторы. Entropy, accuracy и row-loss вычисляются реально.
  Backward пересчитывает logits только для supervised-строк и применяет
  фактический upstream AMP scale до округления градиента в fp16.
- Head пропускает позиции, не нужные ни одной метрике/loss. Frozen MLP
  пропускает padding детерминированных pointwise-операций; attention, Q/V,
  dropout и порядок RNG сохраняют исходные формы. Input IDs, маски и батчи
  не меняются, встроенные packing-режимы не включаются.

Поддерживаемый training-контракт проверяется по фактическим типам, dtype,
режиму AMP и вызывающему SFT loss. Другие модельные вызовы, в частности
отдельная evaluation, сохраняют плотные logits и исходный путь.
Тестируются left/right padding, пограничная shifted label, все ignored labels,
масштабированные градиенты, реальные SFT-метрики и rewind-протокол.

## Ограничения

Цель 2x по памяти выполнена; **2x по полному времени не достигнуты**.
Нельзя сравнивать абсолютные времена разных Kaggle-сессий как изолированный
эффект одного патча. Различие training-loop между base-повторами заметно,
поэтому сохранены оба замера, порядок чередуется штатным harness.
Два самостоятельных fused NF4 GEMM probe дали замедление и не подключены.

Контрольная метка `t4-validated-memory-v5` фиксирует именно проверенный код.
Следующий NF4 backward-кандидат пока не входит в эти измерения.
Результат относится к публичным данным. Финальная публикация Kaggle,
перенос в репозиторий команды и оформление конкурсной сдачи ещё не выполнены.
