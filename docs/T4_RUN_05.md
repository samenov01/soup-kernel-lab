# Дополнительная проверка NF4 backward

Код `6c28bece118576d111a9076176d0f37b1545a6a5`, Kaggle auto версия 9.
Два повтора base/solution, исходный harness и параметры без изменений.
NF4 backward напрямую распаковывает вес в fp16, исключая промежуточный
fp32-вес перед исходным matmul. Packed-веса, scales и исходный QuantState
не изменяются; распакованные веса не кэшируются.
