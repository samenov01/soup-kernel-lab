## Реализация

Основа — полностью recomputed MLP и компактные attention/projection
активации из `a627f39`. Frozen tied embedding/head FP32-параметр размером
890.25 MiB хранится на CPU, сохраняя значения, dtype и связь параметров.
Embedding выбирает строки на CPU и возвращает их на исходную CUDA GPU.
После framework `model.to()` собственный `_apply` восстанавливает CPU storage.

Head использует полный Half-операнд 445.125 MiB на GPU с прежними формами
матричных умножений; разбиение словаря не включено. Сохранённые decoder
активации удерживаются на GPU в пределах бюджета 256 MiB, остальные большие
тензоры без потери значений переносятся в pinned CPU memory и возвращаются
для backward. Пересылки и построение кэшей происходят внутри измеряемого запуска.

Встроенные флаги offload/checkpointing/packing не включались. `harness/`,
`tests/`, `task/`, `templates/` совпадают со стартовым
`c7c2fcd15972ce8b898d8d3ff732ee192c817ceb`. Командный репозиторий хакатона
для этих экспериментов не изменялся. Это допуск на публичных данных;
скрытые проверки и итоговая оценка жюри отдельно не подтверждены.
