## Реализация и точность

Используются vocabulary-редукции, NF4 unpack, RMSNorm, chunked head и
padding MLP из предыдущей версии. Дополнительно:

- Runtime RoPE объединяет rotate/multiply/add и их backward, не компилируясь
  заново для каждой длины батча.
- Frozen gate/up и base Q/K/V объединяются в packed-NF4 матричные умножения.
  Дополнительные packed buffers создаются внутри измеряемого процесса;
  полного dequantized-weight cache нет. Параметры модели не заменяются.
- Gather/cast и scatter/zero-fill проекций объединены. LoRA A/B считают
  действительные строки подряд; scaling/add/backward сохраняют Half-округление.
- В ordinary fp16 SFT decoder Half используется для внутренних активаций
  и residual storage. RMS-статистики и арифметика нормализации остаются FP32,
  final norm возвращает FP32 для head. Dtype весов и trainable-параметров,
  fp16/bf16-флаги, optimizer, LoRA rank/alpha/dropout, данные и шаги не меняются.

FP16-хранение меняет внутреннее округление: побитовая тождественность с
прежними FP32-активациями не заявляется. Dropout остаётся штатным, с теми же
p и формами; одинаковые битовые маски между разными dtype не обещаются.
Первая потеря, все шаги, реальные метрики и независимый adapter eval проверены.
Обычные внешние model/eval-вызовы сохраняют предыдущий путь.

12 собственных кернелов реально запущены в каждом measured solution run.
Исходный SwiGLU-пример не изменён и не засчитывается собственным. Медленный
самостоятельный GQA удалён; native SDPA остаётся в этом проверенном коде.
