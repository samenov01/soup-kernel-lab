## Следующая итерация

`profile_run` равен null. В архиве нет `profile.json`; запуск выполнен без
`--profile` и только с одним повторением. Данных о времени остальных операций
нет, поэтому новый участок оптимизации пока не выбираем на основании догадок.

В текущей Kaggle-сессии, сохранив результаты первого запуска, выполнить:

```python
import subprocess
subprocess.run([
    "python", "harness/run_task.py", "--only", "solution", "--profile",
    "--out", "runs_profile_01",
], cwd="/kaggle/working/repo", check=True)
```

Команда использует штатный harness, не изменяет настройки задачи и пишет в
отдельный каталог. Если этот каталог уже использовался, выбрать новое имя:
harness перезаписывает результаты повторного запуска в том же каталоге.
Не запускать одновременно другую GPU-нагрузку.

Вернуть `runs_profile_01/solution_profile/profile.json`,
`runs_profile_01/result.json` и `runs_profile_01/solution_1/metrics.json`.
Если профилирование завершится ошибкой — также
`runs_profile_01/solution_profile/train.log`.
После выбора и проверки следующей оптимизации нужен финальный запуск
`--repeats 2` с базой и всеми проверками.
